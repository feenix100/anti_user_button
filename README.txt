🧨 Anti-User Button

The impossible-to-click button. Vibe-coded across multiple languages.

🌟 What is this?

The Anti-User Button is a playful UI experiment: a button that constantly dodges your cursor and refuses to be clicked. As soon as you move close, it jumps away in another direction — sometimes with a bit of random chaos thrown in.

It’s intentionally hostile UI, meant for fun, demos, memes, and practicing event-driven programming in different languages.

🔧 Implementations

The button has been vibe-coded in several languages to show how the same mischievous behavior can be recreated across platforms:

JavaScript (HTML + JS) – quick browser demo

Python (Tkinter) – lightweight desktop app

Java – classic desktop implementation

Rust – modern and fast on your local machine

C++ – robust GUI framework example

Visual Basic (Excel VBA) – yes, even in a spreadsheet!

🚀 Why does this exist?

It’s fun 😈

It’s a great way to learn event handling, mouse tracking, and UI positioning

It showcases how similar ideas can be implemented across multiple programming ecosystems

It’s the ultimate test of user patience
